# Задание 2. Chrome DevTools

## Назначение инструмента Chrome DevTools и методы вызова

**Chrome DevTools** — встроенный набор инструментов в браузере Google Chrome, предназначенный для отладки, анализа и оптимизации веб-страниц. Позволяет разработчикам и тестировщикам просматривать и изменять HTML/CSS, отлаживать JavaScript, анализировать сетевые запросы и производительность, а также проверять адаптивность сайта.

### Методы вызова Chrome DevTools:
- Нажать клавишу `F12`.
- Клик правой кнопкой мыши по элементу страницы → выбрать «Просмотреть код» (Inspect).
- Меню Chrome → Дополнительные инструменты → Инструменты разработчика.
- Горячие клавиши:  
  - Windows/Linux: `Ctrl + Shift + I`  
  - Mac: `Cmd + Option + I`

## Вкладки Chrome DevTools и их полезность для тестировщика

### 1. Elements (Элементы)
- Просмотр и редактирование DOM и CSS в реальном времени.
- Проверка верстки, адаптивности, визуальных багов.
- Быстрая корректировка стилей и оценка результата.

### 2. Console (Консоль)
- Отображение ошибок JavaScript и предупреждений.
- Выполнение JS-команд для тестирования и отладки.
- Выявление проблем со скриптами.

### 3. Network (Сеть)
- Анализ сетевых запросов, загрузки ресурсов и API.
- Проверка времени отклика, статусов ответов сервера.
- Симуляция разных условий сети (например, 3G, offline).

### 4. Sources (Источники)
- Просмотр и отладка исходного JavaScript-кода.
- Установка точек останова, пошаговое выполнение кода.
- Поиск и устранение логических ошибок.

### 5. Performance (Производительность)
- Анализ времени загрузки, рендеринга и выполнения скриптов.
- Выявление узких мест и оптимизация производительности.

### 6. Memory (Память)
- Анализ использования памяти, поиск утечек.
- Важен для тестирования стабильности приложений.

### 7. Application (Приложение)
- Управление локальным хранилищем, cookies, кешем.
- Тестирование офлайн-режимов и сохранения данных.

### 8. Security (Безопасность)
- Проверка сертификатов, HTTPS и уязвимостей.
- Контроль безопасности сайта.

### 9. Lighthouse
- Автоматический аудит производительности, доступности, SEO.
- Помогает комплексно оценить качество сайта.

### Объяснение флагов

- **Secure**  
  Этот флаг означает, что cookie передается только по защищенному соединению HTTPS. Помогает защитить данные от перехвата.

- **HttpOnly**  
  Флаг запрещает доступ к cookie через JavaScript, что защищает от некоторых видов XSS-атак.

- **SameSite**  
  Управляет тем, как cookie отправляется при межсайтовых запросах:  
  - `Strict` — cookie отправляется только при переходах с того же сайта.  
  - `Lax` — cookie отправляется при переходах с внешних сайтов, но только для безопасных методов (например, GET).  
  - `None` — cookie отправляется всегда, даже при запросах с других сайтов (обычно требует Secure).

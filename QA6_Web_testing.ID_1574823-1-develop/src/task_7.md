# Задание 7. Валидация HTML

## Проверенный сайт
https://21-school.ru/

## Результаты проверки (валидатор W3C)

### ℹ️ Информационные предупреждения

1. **Info:** Trailing slash on void elements has no effect and interacts badly with unquoted attribute values.
   - Описание: Лишний завершающий слэш (`/`) у пустых элементов HTML (`<meta />`, `<link />`, `<img />` и т.д.) может вызывать некорректную интерпретацию в некоторых браузерах, особенно при отсутствии кавычек у атрибутов.
   - Примеры мест:
     - `<meta charSet="utf-8"/>`
     - `<link rel="icon" href="/favicon/favicon.ico"/>`
     - `<img src="..." alt="..."/>`

   ✔️ Рекомендация: для HTML5 использовать самозакрывающиеся теги без `/` — например `<meta>`, `<link>`, `<img>`.

2. **Warning:** The `type` attribute is unnecessary for JavaScript resources.
   - Местоположение: `<script type="text/javascript">`
   - ✔️ Рекомендация: Атрибут `type="text/javascript"` можно опустить — по умолчанию браузер понимает `<script>` как JavaScript.

---

### ❌ Ошибки разметки

3. **Error:** Element `<p>` not allowed as child of element `<h2>`.
   - Описание: Вложенные абзацы `<p>` не могут находиться внутри заголовков `<h2>`.
   - ✔️ Рекомендация: Перенести `<p>` за пределы `<h2>`, использовать `<span>` или другие инлайновые элементы.

4. **Error:** Element `<ul>` not allowed as child of element `<ul>`.
   - Описание: Списки `<ul>` не должны быть непосредственными детьми других `<ul>` без промежуточного `<li>`.
   - ✔️ Рекомендация: Вложенные списки нужно помещать внутрь `<li>`:
     ```html
     <ul>
       <li>Пункт
         <ul>
           <li>Подпункт</li>
         </ul>
       </li>
     </ul>
     ```

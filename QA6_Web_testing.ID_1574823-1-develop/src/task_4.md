# Задание 4. Протоколы HTTP и HTTPS

## Схема работы HTTPS-протокола

1. **Клиент (браузер) инициирует соединение с сервером по протоколу HTTPS** (порт 443).  
2. **Сервер отправляет клиенту свой цифровой сертификат SSL/TLS**, который содержит открытый ключ и данные об удостоверяющем центре (CA).  
3. **Клиент проверяет сертификат** на подлинность и срок действия, а также удостоверяется, что сертификат выдан доверенным центром.  
4. Если сертификат проверен успешно, **клиент создает случайный ключ сессии (симметричный ключ)** и шифрует его открытым ключом сервера.  
5. **Зашифрованный ключ сессии отправляется серверу.**  
6. **Сервер расшифровывает ключ сессии с помощью своего закрытого ключа.**  
7. После обмена ключами начинается **шифрованный обмен данными (симметричное шифрование)** между клиентом и сервером.  
8. Все последующие HTTP-запросы и ответы передаются в зашифрованном виде, обеспечивая конфиденциальность и целостность данных.

---

## Основные группы кодов состояния HTTP и их значение

| Группа кодов | Описание                                  | Примеры                       |
|--------------|-------------------------------------------|------------------------------|
| **1xx**      | Информационные — запрос получен, продолжайте | 100 Continue                 |
| **2xx**      | Успех — запрос успешно обработан         | 200 OK, 201 Created           |
| **3xx**      | Перенаправления — требуется дополнительное действие | 301 Moved Permanently, 302 Found |
| **4xx**      | Ошибки клиента — запрос некорректен или запрещен | 400 Bad Request, 401 Unauthorized, 404 Not Found |
| **5xx**      | Ошибки сервера — проблема на стороне сервера | 500 Internal Server Error, 503 Service Unavailable |

# Задание 1: Тест-кейсы

## Позитивный тест-кейс: Успешная авторизация на https://www.saucedemo.com/

**ID:** TC001  
**Название:** Авторизация с валидными данными  
**Предусловия:** Открыта страница авторизации https://www.saucedemo.com/  
**Шаги:**
1. Ввести логин `standard_user` в поле Username.
2. Ввести пароль `secret_sauce` в поле Password.
3. Нажать кнопку Login.  
**Ожидаемый результат:** Пользователь попадает на главную страницу приложения.

## Негативный тест-кейс: Ошибка при неверном пароле

**ID:** TC002  
**Название:** Ошибка авторизации при неправильном пароле  
**Предусловия:** Открыта страница авторизации https://www.saucedemo.com/  
**Шаги:**
1. Ввести логин `standard_user` в поле Username.
2. Ввести пароль `wrong_password` в поле Password.
3. Нажать кнопку Login.  
**Ожидаемый результат:** Появляется сообщение об ошибке: "Username and password do not match..."

1. Заголовок страницы отображается корректно (проверка корректности заголовка).
2. Страница доступна по URL (проверка доступности).
3. На странице отображаются все блоки контента (наличие всех разделов).
4. Ссылки на ресурсы работают (все переходы активны).
5. Адаптивность страницы при разных разрешениях экрана (UI адаптация).
6. Тексты читабельны и без ошибок (грамматическая и визуальная проверка).
7. Все изображения загружаются корректно (отсутствие битых ссылок).

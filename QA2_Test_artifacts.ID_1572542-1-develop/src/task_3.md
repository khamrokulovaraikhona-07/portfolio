# Задание 3: Баг-репорт

**Заголовок:** Кнопка "Login" активна при пустых полях логина и пароля  
**Приоритет:** Medium  
**Серьезность:** Major  
**Шаги воспроизведения:**
1. Перейти на https://www.saucedemo.com/
2. Не вводить никаких данных в поля логина и пароля.
3. Нажать кнопку Login.  
**Фактический результат:** Кнопка нажимается, происходит валидация.
**Ожидаемый результат:** Кнопка должна быть неактивна или выводить предупреждение.

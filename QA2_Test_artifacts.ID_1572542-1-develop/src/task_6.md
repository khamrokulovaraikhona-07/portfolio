## Ресурсы для генерации файлов разного размера:
   mockfile.org — Генерирует файлы разных размеров для тестирования (до 1 GB).

1. https://mockfile.org/en/


sample-videos.com — Дает примеры текстовых файлов разных форматов и размеров.


2. https://www.sample-videos.com/download-sample-text-file.php

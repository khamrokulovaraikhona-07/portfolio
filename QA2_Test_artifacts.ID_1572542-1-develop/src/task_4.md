# Задание 4: Тест-план

**Проект:** Сайт «Школа 21» — раздел «Корпоративное обучение»  
**Цель тестирования:** Проверка корректности работы раздела, соответствие UI и UX ожиданиям, отсутствие багов.  
**Объекты тестирования:** Навигация, форма обратной связи, описание программы.  
**Стратегия:** Ручное тестирование по чек-листу и тест-кейсам  
**Критерии начала:** Готовность страницы к тестированию  
**Критерии завершения:** Пройдены все тест-кейсы, исправлены критические баги  
**Риски:** Недоступность ресурса, неправильные данные

## Состояния (States)

# 1. Таблица переходов и состояний

| Откуда                        | Действие пользователя               | Куда                             |
|------------------------------|-----------------------------------|---------------------------------|
| Ожидание ввода               | Ввод данных (логин и пароль)       | Ввод логина и пароля            |
| Ввод логина и пароля         | Нажатие "Войти"                   | Проверка данных                 |
| Проверка данных              | Верные данные                     | Авторизация успешна             |
| Авторизация успешна          | —                                 | Личный кабинет                  |
| Проверка данных              | Неверные данные                   | Ошибка авторизации              |
| Ошибка авторизации           | Повторный ввод                    | Ожидание действия после ошибки  |
| Ожидание действия после ошибки | Нет активности                   | Тайм-аут / неактивность         |

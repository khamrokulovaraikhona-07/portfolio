# Задание 1. Классы эквивалентности — поле ввода логина

## Условие:
Поле допускает любые символы. Ограничений по длине нет. Требуется протестировать с использованием техник классов эквивалентности.

---

## ✅ Позитивный ввод

| Класс эквивалентности               | Пример значения |
|-------------------------------------|------------------|
| Латинские буквы                     | `Username`       |
| Цифры                               | `123456`         |
| Спецсимволы                         | `@#!`            |

---

## ❌ Негативный ввод

| Класс эквивалентности               | Пример значения  |
|-------------------------------------|------------------|
| Пустая строка                       | ``               |
| Длинная строка (1000 символов)      | `aaaaaaaaaa...`  |
| Эмодзи                              | `😀🚀`           |

---

## Вывод:
Для каждого типа ввода (позитивного и негативного) определены три класса эквивалентности. Каждому соответствует одно тестовое значение, как требуется в задании.

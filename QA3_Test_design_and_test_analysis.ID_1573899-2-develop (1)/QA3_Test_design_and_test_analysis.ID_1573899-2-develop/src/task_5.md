## 🧪 Тестовые туры для страницы «Как мы учим» на сайте Школы 21

Для углублённой проверки качества страницы «Как мы учим» на сайте Школы 21 были спроектированы два тестовых тура: **«Путь не туда»** и **«Неуверенный пользователь»**. Цель — выйти за рамки стандартного подхода к тестированию и выявить возможные ошибки, недоступные при обычном прохождении чек-листа.

---

### 🔍 Тур 1: «Путь не туда»

**Суть тура:**  
Этот тур предполагает поведение пользователя, который сознательно (или случайно) действует не по сценарию. Задача — проверить, как страница и элементы интерфейса обрабатывают нестандартные действия и переходы.

**Действия в рамках тура:**
- Переход по некорректным URL: `/kak-my-uchimmmm`, `/kak-my-uchim?error=1`
- Открытие всех ссылок в новых вкладках
- Отключение стилей через DevTools
- Проверка при медленном соединении (эмуляция 2G)
- Смена языка браузера на японский/немецкий
- Отключение JavaScript и проверка доступности контента
- Использование клавиатуры для навигации по странице

**Цель:**  
Выявить слабые места страницы, возникающие при нестандартном использовании.

---

### 🔁 Тур 2: «Неуверенный пользователь»

**Суть тура:**  
Этот тур моделирует поведение пользователя, который часто передумывает, нажимает «назад», закрывает и снова открывает страницу, путается в действиях.

**Действия в рамках тура:**
- Частое нажатие кнопки «Назад» в браузере
- Повторный переход по одной и той же ссылке
- Открытие и немедленное закрытие страницы, повторное возвращение
- Переход через историю браузера
- Взаимодействие с элементами до полной загрузки
- Проверка поведения страницы при эмуляции нестабильного соединения

**Цель:**  
Проверить стабильность и корректность страницы при нестабильных пользовательских сценариях.

---

### 📝 Вывод

Тестовые туры позволяют оценить поведение веб-страницы в условиях, близких к реальным пользовательским ошибкам и нестабильным сценариям, тем самым повышая надёжность и удобство продукта.

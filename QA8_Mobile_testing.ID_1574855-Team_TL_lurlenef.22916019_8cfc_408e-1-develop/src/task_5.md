## Установка и настройка

Charles Proxy установлен на компьютер (Linux/Mac/Windows).  
Установлен сертификат безопасности:  
- На компьютере: `Help → SSL Proxying → Install Charles Root Certificate`  
- На Android: сертификат экспортирован и установлен вручную (Настройки Wi-Fi → Доверие к сертификату)

## Функции Charles Proxy

1. **Фильтрация запросов**  
   Позволяет фильтровать трафик по домену, пути, типу запроса и другим параметрам, что облегчает анализ.

2. **Работа с логами**  
   Все сетевые запросы логируются в реальном времени — можно просматривать методы, заголовки, тела запросов и ответов.

3. **Работа с зашифрованным трафиком**  
   При включении SSL Proxying можно перехватывать и расшифровывать HTTPS-трафик (если установлен сертификат).

4. **Map Remote**  
   Позволяет перенаправлять запросы с одного адреса на другой — полезно при тестировании новых серверов без изменения кода приложения.

5. **Breakpoint**  
   Останавливает запрос или ответ и позволяет вручную изменить их перед отправкой или получением.

6. **Rewrite**  
   Автоматически изменяет содержимое запросов и ответов по заданным правилам (например, подмена заголовков, текста или параметров).

7. **Throttling**  
   Эмулирует медленное или нестабильное сетевое соединение, чтобы протестировать работу приложения в плохих сетевых условиях.
